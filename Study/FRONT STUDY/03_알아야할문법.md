## 1. Jinja2 템플릿 문법

```html
{# 이것은 주석 (렌더링 결과에 포함 안 됨) #}

{# 변수 출력: {{ }} #}
{{ news.title }}
{{ current_user.name if current_user else '게스트' }}
{{ news.created_at.strftime('%Y년 %m월 %d일') }}

{# 제어문: {% %} #}
{% if current_user %}
  <span>{{ current_user.name }}님</span>
{% elif current_user.role == 'admin' %}
  <span>관리자</span>
{% else %}
  <a href="/login">로그인</a>
{% endif %}

{# 반복문 #}
{% for item in news_items %}
  <div class="card">{{ item.title }}</div>
{% endfor %}

{# 반복 + 조건 (for if) #}
{% for para in news.content.split('\n') if para.strip() %}
  <p>{{ para.strip() }}</p>
{% endfor %}

{# 빈 경우 처리 #}
{% for item in items %}
  <li>{{ item }}</li>
{% else %}
  <p>데이터 없음</p>  {# items가 비어있을 때 #}
{% endfor %}

{# 상속 #}
{% extends "base.html" %}
{% block content %}
  ... 내용 ...
{% endblock %}
```

### 자주 쓰는 Jinja2 필터
```html
{{ text | length }}                  → 길이 (문자열, 리스트 모두 가능)
{{ text | truncate(50) }}            → 50자로 잘림 + "..."
{{ value | default("없음") }}        → None이면 "없음"
{{ html_string | safe }}             → HTML 이스케이프 비활성화 (신뢰할 수 있는 콘텐츠만)
{{ number | int }}                   → 정수 변환
{{ list | join(", ") }}              → ["a","b"] → "a, b"
{{ dict | tojson }}                  → Python dict를 JSON 문자열로 (JS에서 사용)
{{ cat.id in subscribed_ids }}       → Python의 in 연산자 그대로 사용 가능
```

## 3. CSS Flexbox

```css
/* 부모에 설정 */
.container {
    display: flex;

    /* 주축 방향 */
    flex-direction: row;         /* 가로 (기본) */
    flex-direction: column;      /* 세로 */

    /* 주축 정렬 */
    justify-content: flex-start; /* 시작점 정렬 (기본) */
    justify-content: center;     /* 가운데 정렬 */
    justify-content: flex-end;   /* 끝점 정렬 */
    justify-content: space-between; /* 양 끝 + 균등 간격 */
    justify-content: space-around;  /* 모든 요소 주위 균등 간격 */

    /* 교차축 정렬 */
    align-items: stretch;        /* 교차축 방향으로 늘림 (기본) */
    align-items: center;         /* 가운데 정렬 */
    align-items: flex-start;     /* 시작점 정렬 */

    /* 줄바꿈 */
    flex-wrap: nowrap;           /* 한 줄 유지 (기본) */
    flex-wrap: wrap;             /* 넘치면 다음 줄 */

    /* 간격 */
    gap: 16px;                   /* 자식 요소 간 간격 */
    column-gap: 20px;            /* 열 간격 */
    row-gap: 10px;               /* 행 간격 */
}

/* 자식에 설정 */
.item {
    flex: 1;          /* flex-grow: 1, flex-shrink: 1, flex-basis: 0% */
    flex: 0 0 200px;  /* grow: 0, shrink: 0, basis: 200px (고정 너비) */
    flex-shrink: 0;   /* 공간 부족해도 줄어들지 않음 */
    align-self: center; /* 이 요소만 개별 교차축 정렬 */
}
```

## 4. CSS Grid

```css
/* 뉴스 카드 그리드 */

    grid-row: 1 / 3;      /* 1~3번 행 차지 (2행 차지) */
    grid-column: span 2;   /* 2열 차지 (간단한 방식) */
}
```

## 5. CSS 선택자

```css
/* 기본 */
div {}            /* 태그 */
.class {}         /* 클래스 */
#id {}            /* id */
* {}              /* 전체 */

/* 조합 */
.parent .child {}   /* 자손 (모든 하위) */
.parent > .child {} /* 직계 자식만 */
.a + .b {}          /* a 바로 다음 형제 b */
.a ~ .b {}          /* a 이후 모든 형제 b */

/* 속성 선택자 */
[data-liked="true"] {}     /* data-liked="true" 인 요소 */
input[type="text"] {}      /* text 타입 input */
a[href^="http"] {}         /* href가 http로 시작 */

/* 가상 클래스 */
a:hover {}          /* 마우스 올렸을 때 */
button:active {}    /* 클릭 중 */
input:focus {}      /* 포커스 상태 */
li:first-child {}   /* 첫 번째 자식 */
li:last-child {}    /* 마지막 자식 */
li:nth-child(2n) {} /* 짝수 번째 자식 */
li:not(.hidden) {}  /* .hidden이 아닌 li */

/* 가상 요소 */
body::before {}     /* body의 앞에 가상 요소 생성 */
p::after {}         /* p의 뒤에 가상 요소 생성 */
```

## 6. CSS 애니메이션 / 트랜지션

```css
/* transition: 상태 변화를 부드럽게 */
.card {
    transition: transform 0.2s ease, box-shadow 0.2s ease;
    /* property | duration | timing-function */
}
.card:hover {
    transform: translateY(-2px);
    box-shadow: 0 8px 24px rgba(0,0,0,0.12);
}

/* transform 함수들 */
transform: translateY(-2px);      /* 세로 이동 */
transform: translateX(10px);      /* 가로 이동 */
transform: scale(1.05);           /* 크기 변경 */
transform: rotate(45deg);         /* 회전 */
transform: translateX(-50%) translateY(-50%); /* 가운데 정렬에 많이 사용 */

/* @keyframes: 복잡한 애니메이션 */
@keyframes fadeIn {
    from { opacity: 0; transform: translateY(10px); }
    to   { opacity: 1; transform: translateY(0); }
}

.modal {
    animation: fadeIn 0.3s ease forwards;
    /* name | duration | timing | fill-mode */
}
```

## 8. DOM 조작

```javascript
// 요소 선택
const el = document.getElementById('btn-like');
const el = document.querySelector('.btn-like');          // 첫 번째
const els = document.querySelectorAll('.news-card');     // 모두 (NodeList)

el.classList.toggle('selected');                         // 없으면 추가, 있으면 제거
el.classList.toggle('selected', condition);             // condition에 따라 추가/제거
el.classList.contains('active');                         // boolean 반환

// 속성 조작
el.dataset.liked = 'true';                              // data-liked 속성 설정
const liked = el.dataset.liked === 'true';              // 항상 string이므로 비교 주의
el.setAttribute('href', '/news/1');
el.getAttribute('data-id');

// 내용 변경
el.textContent = '새 텍스트';          // 텍스트만 (XSS 안전)
el.innerHTML = '<strong>HTML</strong>'; // HTML 파싱 (XSS 주의!)

// 이벤트
el.addEventListener('click', handler);
el.removeEventListener('click', handler);

// 이벤트 객체
el.addEventListener('click', (e) => {
    e.preventDefault();      // 기본 동작 방지 (form 제출, 링크 이동 등)
    e.stopPropagation();     // 이벤트 버블링 중단
    e.target;                // 실제 클릭된 요소
    e.currentTarget;         // 이벤트 리스너가 달린 요소
});

// 스타일 조작
el.style.display = 'none';
el.style.opacity = '0';
el.style.transform = 'translateY(-2px)';
```

```javascript
// JSON 전송 (application/json)
const res = await fetch('/api/chat/room', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ category: '일반문의' })

// FormData 전송 (multipart/form-data) — 파일 업로드에도 사용
const formData = new FormData();
formData.append('content', '댓글 내용');
formData.append('parent_id', 5);
formData.append('file', fileInput.files[0]);

const res = await fetch('/upload', {
    method: 'POST',
    body: formData
    // Content-Type 헤더를 직접 설정하지 않음 (boundary 자동 설정)

// 응답 처리
const data = await res.json();    // JSON 응답
const text = await res.text();    // 텍스트 응답
const blob = await res.blob();    // 파일(이미지 등) 응답
res.status;                       // 상태 코드 (200, 404, 등)
res.ok;                           // 200-299이면 true
```

## 10. WebSocket 문법

```javascript
// 연결
const ws = new WebSocket('ws://localhost:8000/api/chat/ws/1');
// wss://: 보안 WebSocket (HTTPS 환경에서 필수)

// 이벤트 핸들러
ws.onopen    = (e) => { console.log('연결됨'); };
ws.onmessage = (e) => { const data = JSON.parse(e.data); };
ws.onerror   = (e) => { console.error('오류:', e); };
ws.onclose   = (e) => {
    console.log('닫힘, code:', e.code, 'reason:', e.reason);
    // e.code === 1000: 정상 종료
    // e.code === 1006: 비정상 종료 (네트워크 끊김 등)
};

// 데이터 전송
ws.send(JSON.stringify({ type: 'message', content: '안녕' }));

// 연결 상태 확인
ws.readyState;   // 0: CONNECTING, 1: OPEN, 2: CLOSING, 3: CLOSED

// 연결 종료
ws.close(1000, 'normal close');
```

```javascript
// localStorage: 브라우저를 닫아도 유지
localStorage.setItem('theme', 'dark');
const theme = localStorage.getItem('theme');
localStorage.removeItem('theme');

// sessionStorage: 탭 닫으면 삭제
```

## 12. CSS 단위

| 단위 | 의미 | 예시 |
|------|------|------|
| `px` | 절대 픽셀 | `font-size: 16px` |
| `em` | 부모 요소의 font-size 기준 | `1.5em` = 부모 크기의 1.5배 |
| `rem` | root(html) 요소의 font-size 기준 | `1rem` = 보통 16px |
| `%` | 부모 요소 기준 비율 | `width: 50%` |
| `vw` | 뷰포트 너비의 % | `width: 100vw` = 화면 너비 100% |
| `vh` | 뷰포트 높이의 % | `height: 100vh` = 화면 높이 100% |
| `fr` | Grid에서 남은 공간 비율 | `1fr` = 균등 분배 |

```css
/* 반응형 텍스트 크기 */
font-size: clamp(14px, 2vw, 18px);  /* 최소 14px, 뷰포트 2%, 최대 18px */
```
