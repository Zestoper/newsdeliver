## 5. 댓글 시스템 — 대댓글 포함 (news_detail.html)

```javascript
// 댓글 목록 불러오기
async function loadComments() {
    const res = await fetch(`/news/${NEWS_ID}/comments`);
    const comments = await res.json();
    // 서버 응답: [{id, content, user_id, parent_id, name, like_count, created_at, liked}, ...]
    
    renderComments(comments);
}

function renderComments(comments) {
    // parent_id가 null인 댓글 = 최상위 댓글
    const topLevel = comments.filter(c => !c.parent_id);
    // parent_id가 있는 댓글 = 대댓글
    const replies = comments.filter(c => c.parent_id);
    
    topLevel.forEach(comment => {
        const commentEl = createCommentElement(comment);
        // 이 댓글에 달린 대댓글 찾기
        const subReplies = replies.filter(r => r.parent_id === comment.id);
        subReplies.forEach(reply => {
            commentEl.appendChild(createReplyElement(reply));
        });
        container.appendChild(commentEl);
    });
}

// 댓글 작성 (form 제출)
async function submitComment(e) {
    e.preventDefault();  // 기본 form 제출 방지
    const content = document.getElementById('comment-input').value;
    
    const formData = new FormData();
    formData.append('content', content);
    // 대댓글이면: formData.append('parent_id', parentId);
    
    await fetch(`/news/${NEWS_ID}/comments`, {
        method: 'POST',
        body: formData   // Content-Type: multipart/form-data 자동 설정
    });
    await loadComments();  // 새로고침 없이 목록 재로드
}
```

**이메일 HTML의 특수성:**
- Gmail, Outlook 등 이메일 클라이언트는 외부 CSS를 차단합니다.
- 따라서 모든 스타일을 `style="..."` 인라인으로 작성합니다.
- `<link>`, `<style>` 태그가 무시될 수 있습니다.
- `flexbox`, `grid`가 Outlook에서 지원 안 될 수 있어 `table` 레이아웃이 안전합니다.

## 11. 구독 페이지 — 카테고리 체크박스 UI (subscribe.html)

```html
<!-- Jinja2로 카테고리 목록 렌더링 -->
{% for cat in categories %}
  {% if not cat.name.startswith('해외') %}
  <button class="cat-btn {% if cat.id in subscribed_ids %}selected{% endif %}"
          data-id="{{ cat.id }}"
          data-global="0"
          onclick="toggleCat(this)">
    {{ cat.name }}
  </button>
  {% endif %}
{% endfor %}
```

```javascript
async function toggleCat(btn) {
    const catId = btn.dataset.id;
    const isGlobal = parseInt(btn.dataset.global);
    
    // 서버에 POST 요청
    const res = await fetch(`/categories/${catId}/subscribe`, {
        method: 'POST',
        headers: {'Content-Type': 'application/json'},
        body: JSON.stringify({is_global: isGlobal})  // JSON 전송
    });
    const data = await res.json();
    
    if (data.success) {
        btn.classList.toggle('selected', data.subscribed);  // 클래스 토글
    }
}
```

**`classList.toggle(class, force)` :**
- `force`가 `true`면 클래스 추가, `false`면 제거
- 서버 응답의 `data.subscribed`에 따라 UI를 정확히 동기화

## 12. 검색 페이지 — 폼 제출 (search.html)

```html
<!-- GET 방식 폼: URL에 검색어가 포함됨 (?q=...&source=...) -->
<form method="GET" action="/search">
    <input type="text" name="q" value="{{ q }}" placeholder="뉴스 검색...">
    <select name="source">
        <option value="">전체 언론사</option>
        {% for src in sources %}
        <option value="{{ src }}" {% if src == selected_source %}selected{% endif %}>
            {{ src }}
        </option>
        {% endfor %}
    </select>
    <button type="submit">검색</button>
</form>
```

**GET vs POST 폼:**
- `GET`: 검색, 필터 → URL에 파라미터 포함 → 북마크/공유 가능
- `POST`: 로그인, 회원가입, 데이터 변경 → URL에 파라미터 없음 → 새로고침 시 재제출 경고
