## 1. lifespan — 서버 시작/종료 시 실행 코드 (`app/main.py`)

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    import threading
    threading.Thread(target=_fetch_news_job, daemon=True).start()  # 시작 즉시 뉴스 수집
    
    scheduler = BackgroundScheduler(timezone=KST)
    scheduler.add_job(_newsletter_job, CronTrigger(hour=7, minute=30, timezone=KST))
    scheduler.add_job(_newsletter_job, CronTrigger(hour=18, minute=30, timezone=KST))
    scheduler.add_job(_fetch_news_job, CronTrigger(hour="*/2", minute=0, timezone=KST))
    scheduler.start()
    yield          # ← 여기서 서버가 실행됨
    scheduler.shutdown()
```

**포인트:**
- `daemon=True` : 메인 프로세스 종료 시 스레드도 자동 종료
- `yield` 전: 서버 시작 직후 실행 / `yield` 후: 서버 종료 시 실행
- `CronTrigger(hour="*/2")` : 2시간마다 실행 (0, 2, 4, 6 ... 22시)

## 2. 쿠키 인증 — get_current_user (`app/routers/pages.py`)

```python
AUTH_COOKIE_NAME = "newsletter_user"

def get_current_user(request: Request) -> dict | None:
    user_id = request.cookies.get(AUTH_COOKIE_NAME)  # 쿠키에서 user_id 읽기
    if not user_id:
        return None
    with engine.connect() as conn:
        row = conn.execute(
            text("SELECT * FROM news_users WHERE id = :id"),
            {"id": user_id}
        ).fetchone()
        return dict(row._mapping) if row else None
```

**포인트:**
- 쿠키에는 user_id 문자열만 저장 (DB에서 매 요청마다 조회)
- `row._mapping` : SQLAlchemy Row를 딕셔너리로 변환하는 방법
- 쿠키가 없거나 DB에 해당 유저가 없으면 `None` 반환
- 로그인 설정: `response.set_cookie(key=AUTH_COOKIE_NAME, value=user_id, httponly=True, samesite="lax")`

## 3. Groq AI 요약 — 레이트 리밋 + 재시도 (`app/services/ai_summary.py`)

```python
_groq_lock = threading.Lock()
_last_call_time = 0.0
_MIN_INTERVAL = 6.0  # 분당 10회 제한

def _call_groq(title, content, is_global=False, fast_fail=False):
    body = content.strip().replace("\n", " ")[:800]  # 입력 토큰 절약
    
    with _groq_lock:  # 동시 호출 완전 차단 (직렬화)
        global _last_call_time
        
        for attempt in range(5):          # 최대 5번 재시도
            elapsed = time.time() - _last_call_time
            if elapsed < _MIN_INTERVAL:
                time.sleep(_MIN_INTERVAL - elapsed)   # 6초 보장
            _last_call_time = time.time()
            
            res = httpx.post(GROQ_URL, ...)
            if res.status_code == 429:    # Rate Limit 초과
                if fast_fail:
                    return ""             # 이메일 발송 시 블로킹 방지
                time.sleep(60 if attempt >= 1 else 5)
                continue
```

**포인트:**
- `threading.Lock()` : 스레드 안전(thread-safe) 직렬화. with 블록 진입 시 Lock 획득, 나가면 자동 해제
- `fast_fail=True` : 뉴스레터 발송 중 429가 오면 요약 없이 계속 진행 (발송 차단 방지)
- 해외뉴스: `EN:::` / `KO:::` 형식 응답 검증 후 재시도

## 5. 해외뉴스 카테고리 자동 분류 (`app/services/global_news.py`)

```python
def _classify(title, description, hint_category) -> str | None:
    text_lower = title.lower() + " " + (description or "").lower()
    
    # 1단계: 정치 차단 키워드 확인
    if any(_kw_match(t, text_lower) for t in POLITICS_BLOCK_TERMS):
        if any(_kw_match(k, text_lower) for k in _REROUTE_ECO):
            return "경제"   # 경제 관련이면 경제로 라우팅
        if any(_kw_match(k, text_lower) for k in _REROUTE_INTL):
            return "국제"   # 국제 관련이면 국제로 라우팅
        return "정치"

    # 2단계: 카테고리별 키워드 점수 계산
    scores = {
        cat: sum(2 for kw in kws if _kw_match(kw, title.lower()))  # 제목 = 2점
            + sum(1 for kw in kws if _kw_match(kw, description.lower()))  # 설명 = 1점
        for cat, kws in REQUIRED.items()
    }
    
    best_cat = max(scores, key=scores.get)
    if scores[best_cat] > scores.get(hint_category, 0):
        return best_cat   # 계산된 최고 카테고리
    return hint_category  # 점수 같으면 RSS 소스 힌트 우선
```

**포인트:**
- `_kw_match()` : 단어 경계(`\b`)를 고려한 정확한 매칭 (`tech` ≠ `technology`의 일부)
- 점수가 0이면 `None` 반환 → 저장하지 않음 (관련 없는 기사 필터링)

## 7. WebSocket 채팅 (`app/routers/chat.py`)

```python
class _ConnectionManager:
    def __init__(self):
        self.rooms: Dict[int, List[WebSocket]] = {}  # {room_id: [ws1, ws2, ...]}

    async def connect(self, ws, room_id):
        await ws.accept()
        self.rooms.setdefault(room_id, []).append(ws)

    async def broadcast(self, room_id, data: dict):
        for ws in list(self.rooms.get(room_id, [])):  # list()로 복사 (순회 중 변경 방지)
            try:
                await ws.send_json(data)
            except Exception:
                pass  # 연결 끊긴 소켓 무시

@router.websocket("/ws/{room_id}")
async def chat_ws(websocket, room_id):
    await manager.connect(websocket, room_id)
    try:
        while True:
            data = await websocket.receive_json()
            # DB 저장 후 같은 방 모두에게 broadcast
            await manager.broadcast(room_id, {...})
    except WebSocketDisconnect:
        manager.disconnect(websocket, room_id)
```

**포인트:**
- 인메모리 딕셔너리로 연결 관리 → 서버 재시작 시 초기화 (단일 서버에서만 작동)
- `list()` 복사 후 순회: 순회 중 연결 해제 시 RuntimeError 방지
- `WebSocketDisconnect` 예외로 연결 해제 감지

## 8. 본문 정제 — clean_article_text (`app/services/naver_news.py`)

```python
def clean_article_text(text: str) -> str:
    text = _normalize_chars(text)        # &nbsp;, 특수 따옴표 → 일반 문자
    text = _INLINE_NOISE_RE.sub('', text)  # 단독 줄 노이즈 제거 (Advertisement 등)
    
    # 사진 출처, 기자명, 이메일 제거
    text = re.sub(r'[(\[]\s*사진\s*[=:][^\)\]]{1,30}[\)\]]', '', text)
    text = re.sub(r'\n[ \t]*\S{1,6}\s*기자[ \t]*\n', '\n', text)
    
    # 가장 앞쪽에 나오는 푸터/저작권 마커 기준으로 자름
    earliest_idx = len(text)
    for marker in _FOOTER_MARKERS:   # '※', '©', '무단 전재', 'More from BBC' 등 50개
        idx = text.find(marker)
        if idx != -1 and idx < earliest_idx:
            earliest_idx = idx
    text = _cut_at(text, earliest_idx)  # 문장 경계에서 자름
```

**포인트:**
- BeautifulSoup 없이 순수 정규표현식(re)만 사용
- `_cut_at()` : 단순 인덱스 자르기 대신 마지막 문장 끝('. ', '다.', '요.')에서 자름
- `_FOOTER_MARKERS` : 한국어/영어 푸터 패턴 50개 이상 등록
