Project Overview

NewsDeliver

Naver News API로 뉴스를 수집하고, Groq LLaMA 3.1이 요약하며,
하루 두 번 구독자 맞춤 뉴스레터로 전달하는 백엔드 자동화 플랫폼.

Python 3.12 FastAPI MySQL Groq LLaMA 3.1 WebSocket APScheduler OAuth 2.0
About

뉴스를 더 스마트하게

하루에도 수천 건의 뉴스가 쏟아집니다. NewsDeliver는 네이버 뉴스 API로 9개 카테고리의 최신 기사를 2시간마다 자동 수집하고, AI가 핵심을 요약해 바쁜 일상 속에서도 꼭 필요한 뉴스만 빠르게 확인할 수 있도록 돕습니다.

AI 뉴스 요약

Groq AI(LLaMA 3.1)가 긴 기사를 3~4줄로 핵심만 압축합니다. 요약 결과는 DB의 ai_summary 컬럼에 저장되어 재요청 시 API 재호출 없이 재사용됩니다.

맞춤 이메일 뉴스레터

관심 카테고리 구독 시 07:30·18:30 자동 발송. 중복 방지 테이블로 같은 기사 재발송 차단.

실시간 자동 수집

APScheduler가 2시간 주기로 국내·해외 뉴스를 동시 수집. 오분류 기사 재분류 로직도 주기마다 실행.

실시간 채팅 문의

WebSocket 기반 1:1 채팅. 이미지·비디오 파일 업로드 지원, 읽음 상태 실시간 동기화.

북마크 & 댓글

기사 저장, 댓글·대댓글(parent_id) 구조, 댓글 좋아요. 좋아요·댓글 수 기준 인기 기사 집계.

언론사 기사 작성

관리자 승인 후 press 권한 부여. 언론사 계정이 직접 기사를 작성·게시, 신고 처리 시스템 연동.

AI Pipeline

AI 활용 파이프라인

단순 AI 도구 사용이 아닌, 뉴스 수집부터 이메일 발송까지 전 과정을 자동화한 백엔드 파이프라인입니다.

STEP 01

뉴스 자동 수집

APScheduler로 2시간 주기 자동 실행.
Naver News API + RSS 피드 파싱으로 국내·해외 뉴스를 동시 수집.

STEP 02

카테고리 자동 분류

키워드 스코어링으로 9개 카테고리 자동 분류.
정치 재분류 로직이 수집 주기마다 오분류 기사를 보정.

STEP 03

Groq AI 요약

Groq LLaMA 3.1 API로 긴 기사를 3~4줄로 압축.
DB의 ai_summary 컬럼에 저장해 요청마다 재호출 없이 재사용.

STEP 04

맞춤 뉴스레터 발송

07:30·18:30 자동 발송.
newsletter_sent 테이블로 중복 방지. 구독자별 카테고리 5건 필터링 후 SMTP 발송.

Values

우리가 추구하는 가치

NewsDeliver가 뉴스를 전달하는 방식에 담긴 철학입니다.

정확성

신뢰할 수 있는 출처에서 뉴스를 수집합니다. AI 요약도 원문의 맥락을 최대한 보존합니다.

효율성

바쁜 하루 속에서 중요한 뉴스를 빠르게 파악할 수 있도록, 핵심만 정리해 드립니다.

개인화

모든 뉴스를 읽을 필요는 없습니다. 관심 카테고리만 구독해 나만의 뉴스 피드를 만드세요.

신뢰성

언론사 회원은 관리자 승인 후 기사를 게시할 수 있습니다. 검증된 콘텐츠만 제공합니다.

Architecture

백엔드 아키텍처

FastAPI + MySQL 기반의 RESTful API 서버. 7개 라우터, 14개 DB 테이블로 구성된 뉴스 플랫폼입니다.

API Endpoints
메서드 엔드포인트 설명
GET /api/news 뉴스 목록 조회 (최신순, 페이지네이션)
POST /api/news 뉴스 등록 (관리자 / 언론사)
PUT /api/news/{id} 뉴스 수정 (부분 업데이트)
DELETE /api/news/{id} 뉴스 삭제
WS /api/chat/ws/{room_id} WebSocket 실시간 채팅 (파일 업로드·읽음 상태)
GET /api/age-news 연령대별 맞춤 뉴스 추천 (10대 / 30대 / 50대)
GET /api/market KOSPI · KOSDAQ · 환율 실시간 조회
POST /api/users/login JWT 로그인 (이메일 / 소셜)
GET /oauth/{provider}/callback OAuth 소셜 로그인 콜백 (카카오 · 네이버 · 구글)
POST /api/news/{id}/like 좋아요 토글 (JWT 인증 필요)
